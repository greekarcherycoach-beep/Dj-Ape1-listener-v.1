# Dj Ape1 Listener – Android APK

## Βήματα (debug APK)
1. Ανέβασε ΟΛΑ τα αρχεία σε νέο repository στο GitHub (μαζί με τον κρυφό φάκελο `.github`). Το logo και το εικονίδιο υπάρχουν ήδη στο `www/assets/`.
2. **Actions → Build APK → Run workflow** (ή απλά κάνε push).
3. Σε 4–8 λεπτά κατέβασε το artifact **DjApe1-Listener-APK** και εγκατέστησε το `app-debug.apk` (επέτρεψε «εγκατάσταση από άγνωστες πηγές»).

## Τι περιέχει
- **Αναπαραγωγή στο παρασκήνιο:** foreground service με ειδοποίηση (τίτλος/καλλιτέχνης, κουμπί Stop), wake lock και wifi lock. Ο ήχος συνεχίζει με κλειδωμένη οθόνη. Το κουμπί Back ελαχιστοποιεί την εφαρμογή (δεν τη σταματά). Το «σβήσιμο» της εφαρμογής από τα πρόσφατα σταματά τον ήχο.
- **Σάρωση QR:** κουμπί «📷 Σάρωση QR του σταθμού». Διαβάζει το QR που δημιουργεί το host panel (`http://σταθμός/?code=...`) ή σύνδεσμο `djape1://listen?server=σταθμός&code=ΚΩΔΙΚΟΣ`. Συμπληρώνει διεύθυνση και κωδικό. Την πρώτη φορά μπορεί να κατεβάσει τον σαρωτή από τις Υπηρεσίες Google.
- **Deep link:** ανοίγει την εφαρμογή με σύνδεσμο `djape1://listen?server=...&code=...`.
- **Τελευταία 5 τραγούδια:** κάτω από την κάρτα (κουμπί «⌄ Τελευταία 5 τραγούδια» ή scroll). Καταγράφονται όσα παίζουν όσο είσαι συνδεδεμένος και αποθηκεύονται στη συσκευή.
- **Άλλα:** sleep timer, αγαπημένες εκπομπές ★ με υπενθύμιση 5΄ πριν (επαναλαμβανόμενη, δουλεύει και με κλειστή εφαρμογή), ειδοποίηση νέας εκπομπής όσο ακούς, αυτόματη επανασύνδεση σε αλλαγή δικτύου, εξοικονόμηση δεδομένων (MP3 192 σε δίκτυο κινητής), αποθήκευση server/κωδικού/ονόματος, εικονίδιο εφαρμογής από το logo.

## Σημαντικό: CORS στον server του σταθμού
Η εφαρμογή τρέχει από δική της διεύθυνση (`http://localhost`). Ο server πρέπει να στέλνει `Access-Control-Allow-Origin: *` τουλάχιστον στα **`/events`** (τώρα παίζει) και **`/guide`** (πρόγραμμα). Ο ήχος και τα εξώφυλλα δουλεύουν και χωρίς αυτό.

## Σημειώσεις
- Οι υπενθυμίσεις εκπομπών προγραμματίζονται με την ώρα του σταθμού· χρειάζεται η συσκευή να έχει την ίδια ζώνη ώρας.
- Σε Android 13+ η εφαρμογή ζητά άδεια ειδοποιήσεων. Χωρίς αυτήν ο ήχος παίζει, αλλά δεν φαίνεται η ειδοποίηση/υπενθυμίσεις.
- Σε κάποια κινητά (Xiaomi, Huawei, Samsung) βάλε την εφαρμογή σε «Χωρίς περιορισμούς» στη μπαταρία για να μην την κόβει το σύστημα.

## Signed release (APK + AAB για Play Store)
1. Φτιάξε keystore (μία φορά, φύλαξέ το σε ασφαλές μέρος):

       keytool -genkeypair -v -keystore release.jks -alias djape1 -keyalg RSA -keysize 2048 -validity 10000

2. `base64 -w0 release.jks` και βάλε το αποτέλεσμα στα GitHub **Secrets** (Settings → Secrets and variables → Actions):
   `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` (π.χ. `djape1`), `KEY_PASSWORD`.
3. **Actions → Build signed release → Run workflow**. Κατεβάζεις `DjApe1-release.apk` και `DjApe1-release.aab`.

## Τι δεν περιλαμβάνεται
Android Auto, Chromecast και home-screen widget (θέλουν εντελώς native player), καθώς και push από server (θέλει Firebase).
